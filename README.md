## ✨ المميزات

### شاشة الدخول
- دخول بـ **رقم التسجيل + الرقم السري** فقط.
- لا تُعرض أي بيانات دخول داخل الواجهة، وبيانات القائد تُمرَّر عبر **متغيّرات سرّية** (`--dart-define`) عند البناء.

### بطاقة العضو
- مبنية على **قالب النادي الرسمي** (البطاقة البنفسجية) ويُطبع فوقها: الاسم، اللقب، التخصص، المستوى الدراسي، السنة الدراسية، وصورة العضو.
- **قابلة للقلب بالضغط** (حركة 3D) — الوجه الخلفي يعرض رقم التسجيل، الهاتف، البريد، تاريخ الانضمام، الصفة، و**رمز QR** لبطاقة العضو.

### المزامنة السحابية ☁️
- قاعدة الأعضاء تُخزَّن في **Cloudflare R2** عبر Worker خاص بالنادي.
- القائد يضيف/يعدّل/يحذف → يُرفع التغيير تلقائياً، وكل جهاز يسحب أحدث نسخة عند الفتح.
- الدمج آمن: الأحدث يفوز (Last-Write-Wins) + سجل حذف (Tombstones) حتى لا تعود البطاقات المحذوفة.
- زر **مزامنة الآن** مع حالة آخر مزامنة في شاشة الإعدادات.

### لوحة القيادة (القائد)
- **نظرة عامة**: إحصائيات فورية + رسوم توزيع حسب التخصص والسنة الجامعية + أحدث الأعضاء.
- **الأعضاء**: بحث فوري، فلترة بالتخصص والسنة، عرض البطاقة، تعديل، حذف، وإضافة عضو جديد بكل بياناته وصورته.
- **الإعدادات**: تغيير رقم تسجيل القائد ورقمه السري، نسخ قائمة الأعضاء لـ Excel، وإدارة البيانات.

## 🔐 الأسرار (Secrets)

| السر | الوصف |
|---|---|
| `LEADER_REG_B64` | رقم تسجيل القائد مُرمّز Base64 |
| `LEADER_PASS_B64` | الرقم السري للقائد مُرمّز Base64 |
| `KEYSTORE_BASE64` | مفتاح توقيع APK (Base64) |
| `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD` | بيانات المفتاح |
| `CLOUDFLARE_API_TOKEN` | نشر الموقع على Cloudflare + نشر Worker |
| `CLOUDFLARE_ACCOUNT_ID` | معرّف حساب Cloudflare |
| `SYNC_URL` / `SYNC_KEY` | رابط خدمة المزامنة ومفتاحها |

جميع الأسرار مضبوطة في المستودع، والبناء يمرّرها للتطبيق عبر `--dart-define` — لا تظهر أي بيانات دخول داخل الواجهة أو الكود.
