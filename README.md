# 🎓 EPC — نادي رواد الاقتصاد | Economics Pioneers Club

تطبيق **Flutter** كامل لنادي جامعي: تسجيل دخول برقم التسجيل والرقم السري، بطاقة عضو قابلة للقلب، ولوحة تحكم شاملة للقائد.

> **Learn • Innovate • Lead • Succeed**

---

## ✨ المميزات

### 👤 للعضو
- واجهة تسجيل دخول بـ **رقم التسجيل + الرقم السري** → ينقلك مباشرة إلى بروفايلك
- **بطاقة عضو** بتصميم النادي (بنفسجي) تعرض: الاسم، اللقب، التخصص، المستوى الدراسي، السنة الدراسية، والصورة
- البطاقة **قابلة للقلب بالضغط عليها** — الوجه الخلفي يعرض رقم التسجيل، الهاتف، البريد، تاريخ الانضمام والصفة
- تغيير الصورة الشخصية من البروفايل

### 👑 للقائد (لوحة التحكم)
- دخول خاص بحساب القائد
- **إضافة أعضاء** بكل معلوماتهم وصورهم (الاسم، اللقب، التخصص، المستوى، السنة، رقم التسجيل، الرقم السري، الهاتف، البريد، الصورة)
- تعديل وحذف الأعضاء
- **لوحة تحكم شاملة**: إحصائيات (إجمالي الأعضاء، القادة، التخصصات)، رسوم بيانية حسب التخصص وحسب السنة الجامعية
- بحث فوري + فلترة حسب التخصص والسنة
- نسخ قائمة الأعضاء (لصق في Excel/Word)
- عرض بطاقة أي عضو

## 🌐 الموقع والتطبيق

- **الموقع (Web):** يُنشر تلقائياً عبر GitHub Pages بعد نجاح الـ Workflow — الرابط يظهر في صفحة المستودع على GitHub (قسم About / Pages) بصيغة: `https://aitecomp.github.io/epc_app/`
- **تطبيق Android (APK):** يُبنى تلقائياً ويُرفع في **Releases** — حمّل `app-release.apk` وثبّته على هاتفك

## 🚀 البناء المحلي

```bash
flutter pub get
flutter run            # تشغيل على جهاز/محاكي
flutter build web --release     # نسخة الويب
flutter build apk --release     # نسخة Android
```

## 🛠️ التقنيات
